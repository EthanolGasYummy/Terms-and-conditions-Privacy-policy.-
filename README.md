# MCDuels Checker — Legal Site

This is the Terms of Service and Privacy Policy website for the MCDuels Checker Discord bot.

## How to host for free on GitHub Pages

1. Go to [github.com](https://github.com) and create a free account if you don't have one
2. Click **New repository**
3. Name it exactly: `mcduels-checker-legal` (or anything you want)
4. Set it to **Public**
5. Click **Create repository**
6. Click **uploading an existing file** → drag in `index.html` → click **Commit changes**
7. Go to **Settings** → **Pages** (left sidebar)
8. Under **Source** select **Deploy from a branch** → branch: `main` → folder: `/ (root)` → **Save**
9. Wait ~1 minute then your site is live at:
   `https://YOUR-USERNAME.github.io/mcduels-checker-legal/`

That URL is what you put in the Discord Developer Portal under the Terms of Service and Privacy Policy fields.
